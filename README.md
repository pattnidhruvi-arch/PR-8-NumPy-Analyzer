# PR-8 NumPy Analyzer

This project demonstrates basic NumPy operations.

## Features
- Create 2D array
- Calculate Mean, Median, Std Dev, Max, Min, Sum
- Transpose and Reshape operations

## How to Run
pip install numpy
python main.py

## Output
Mean, Median and other stats of the array.
